🎡 Spin the Bias

Spin the Bias is a playful, wheel-of-fortune–style interactive that explores how gender bias appears in healthcare systems, data practices, and technologies.

It looks like a game.
It behaves like a system.

The wheel feels random — but the outcomes represent repeatable patterns in research design, algorithms, and clinical routines.

🧠 Concept

The project uses a familiar game mechanic (a spinning wheel) to represent how bias can feel like “bad luck” to individuals, while actually being produced systematically.

The cheerful, game-show tone is intentional:
serious consequences are often normalized, minimized, or hidden behind neutral interfaces.

🎮 How it works

Click SPIN THE BIAS

The wheel lands on a category (e.g. clinical trials, AI diagnosis, pain scales)

The system generates an outcome explaining:

why the bias happens

what goes wrong

the real-world impact

what could improve it

Spin multiple times to see how:

randomness → repetition → system

📊 Interface logic
System damage

A cumulative score representing how repeated small biases build up into large consequences over time.

Each spin adds damage based on severity.

Trust meter

A rough indicator of confidence in the system.
As system damage increases, trust decreases — reflecting how people lose faith when they are repeatedly dismissed or misserved.

Outcome structure

Each result follows the same logic:

Why it happens

What goes wrong

Real-world impact

What would improve it

This makes individual cases comparable and highlights patterns.
